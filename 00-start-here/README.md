# 00 — Start Here

## Purpose

Establish the learner baseline, course objective and operating method.

## Current Baseline

- Git fundamentals: intermediate
- GitHub platform operation: beginner
- Strongest areas: repositories, commits, branches, diffs, clone/pull/push
- Main gaps: Issues, Pull Requests, Projects, Actions, Releases, governance, security and AI-agent workflows

## Learning Method

1. Learn the concept.
2. Use it inside this repository.
3. Demonstrate the skill without copying instructions.
4. Apply it to a real operating workflow.

## End State

Operate GitHub as a professional change-management, collaboration, automation and governance platform rather than merely as cloud storage for Git repositories.
