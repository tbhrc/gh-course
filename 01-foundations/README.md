# 01 — Foundations

## Mental model

- **Repository** — a governed home for a body of work.
- **Commit** — a durable snapshot with provenance.
- **Branch** — an isolated line of work.
- **Default branch** — the current integrated baseline.
- **Fork** — a separate repository lineage, not merely another branch.

## Operator question

Before changing anything, ask:

> What is the owner of this truth, and what GitHub object best represents the work?

## Exercise

Inspect a commit on `main` and identify its parent, changed files, author/committer and message. Explain why a commit is evidence, but not automatically proof that the desired outcome works.
