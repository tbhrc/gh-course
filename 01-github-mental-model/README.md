# 01 — GitHub Mental Model

## Objective

Understand GitHub as a change-management operating platform built around repositories.

## Core Flow

```text
Organisation
  ↓
Repository
  ↓
Issue
  ↓
Branch
  ↓
Commit
  ↓
Pull Request
  ↓
Checks
  ↓
Merge
  ↓
Release
  ↓
Deployment
```

## Key Distinctions

- Git = version-control system.
- GitHub = hosted platform around Git repositories.
- Commit = save a logical change into Git history.
- Push = send commits to a remote repository.
- Pull Request = propose and review changes before merging.

## Operator Principle

Every meaningful change should have context, history and evidence.

## Practical Exercise

Trace one real change in this repository from file edit to commit history and identify where an Issue, branch and Pull Request would fit.
