# 02 — Issues: GitHub's Work Engine

## Objective

Use GitHub Issues to capture, classify, assign, prioritise and close work with durable context.

## Learn

- Issue anatomy
- Labels
- Assignees
- Milestones
- Sub-issues and dependencies
- Templates
- Closing keywords
- Linking Issues to branches, commits and Pull Requests

## Practical Exercise

Create a real Issue in this repository and take it from open work to completed work with linked evidence.
