# 02 — Issues

Issues are the default durable work object when there is a concrete outcome to achieve.

A useful Issue answers:
- What outcome is required?
- Why does it matter?
- What is in scope and out of scope?
- What evidence proves completion?

## Minimal pattern

```text
Objective
Context
Scope
Verification
Acceptance
```

Do not use Issues as scratchpads, number reservations or duplicated copies of canonical research/documents.

## Exercise

Create a small practice Issue for improving one sentence in this course. Write acceptance criteria that another person could verify without asking you what you meant.
