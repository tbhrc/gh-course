# 03 — Branches & Pull Requests

A branch isolates proposed work. A Pull Request is the review and integration boundary.

```text
Issue
→ branch
→ commits
→ Pull Request
→ review/checks
→ merge
```

A good PR is focused, explains the outcome, links the work object and shows enough evidence to judge whether it should become part of the baseline.

## Exercise

Complete one tiny course correction through an Issue-linked branch and PR. Before merge, inspect the diff rather than relying only on the PR description.
