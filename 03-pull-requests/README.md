# 03 — Pull Requests: The Control Gate

## Objective

Use Pull Requests as the controlled review and acceptance layer for changes.

## Learn

- PR anatomy
- Base vs head branches
- Diffs and changed files
- Reviews and comments
- Checks
- Draft PRs
- Merge methods
- Linking Issues
- Safe AI-agent change review

## Practical Exercise

Make a small change on a branch, open a Pull Request, inspect the diff, review it and merge it.
