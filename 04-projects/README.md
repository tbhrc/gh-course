# 04 — Projects

GitHub Projects are portfolio views over work objects. They should help answer questions such as:
- What is ready?
- What is blocked?
- What is in progress?
- What needs review?
- What is done?

Projects should not become a second manually maintained source of truth for facts already owned by Issues, PRs or domain systems.

## Exercise

Create or inspect a Project view that groups Issues by status. Explain which fields belong in the Project and which facts should remain in the underlying Issue.
