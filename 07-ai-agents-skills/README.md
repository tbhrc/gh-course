# 07 — AI Agents & Skills

GitHub can host several kinds of AI operating instructions and capabilities.

```text
always-on repository rule → AGENTS.md / instructions
reusable method           → Skill
specialist recurring role → custom agent
external capability       → MCP / API / connector
lifecycle command         → hook / Action
```

Choose the smallest mechanism that solves the real problem.

For TBHRC, reusable Skills live centrally in `tbhrc/skills`; this public course must not create competing editable Skill copies.

## Exercise

Classify each requirement as repository instruction, Skill, agent, Action/hook or MCP/API:
1. every PR must avoid exposing secrets;
2. reusable process for building a candidate submission brief;
3. specialist security reviewer;
4. deterministic formatter after edits;
5. access to an external CRM.
