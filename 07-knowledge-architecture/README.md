# 07 — GitHub Knowledge Architecture

## Objective

Learn where information should live inside GitHub and how to avoid creating a dumping ground.

## Compare

- `README.md`
- `/docs`
- Wiki
- Issues
- Discussions
- Projects
- Releases
- Repository files

## Practical Exercise

Classify a sample set of FolderDesk, Talent Bridge and iMPLEMENTAi information into the correct GitHub knowledge location.
