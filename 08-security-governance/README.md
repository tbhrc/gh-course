# 08 — Security & Governance

## Objective

Operate repositories safely, especially when AI agents can create or modify code.

## Learn

- Repository permissions
- Branch protection and rulesets
- Required reviews and checks
- CODEOWNERS
- Secrets and environments
- Secret scanning and push protection
- Dependency security
- Auditability

## Practical Exercise

Define a minimum-safe governance policy for an AI-assisted production repository.
