# 09 — AI Agents + GitHub

## Objective

Use GitHub as the durable control layer between human decisions and AI coding agents.

## Learn

- Issue-driven agent work
- Branch isolation
- Agent commits
- Pull Request creation
- Automated checks
- Human and AI review
- Merge controls
- Agent permissions
- Audit trails

## Reference Flow

```text
Issue
→ agent
→ branch
→ implementation
→ tests
→ Pull Request
→ review
→ merge
→ Actions
→ deployment
→ Issue closes
```

## Practical Exercise

Run one bounded change through an AI agent using an Issue, branch and Pull Request instead of direct edits to `main`.
