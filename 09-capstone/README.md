# 09 — Capstone

Complete one real GitHub improvement end to end.

## Required evidence

1. Define the problem in an Issue.
2. Identify the correct owner/source of truth.
3. Choose the smallest GitHub mechanism.
4. Work on an isolated branch when appropriate.
5. Open a focused PR.
6. Inspect the actual diff.
7. Run the relevant verification.
8. Merge only when acceptance is met.
9. Confirm the merged state.
10. Explain what was learned and whether any reusable learning belongs elsewhere.

## Mastery test

You should be able to explain not just **what you clicked**, but:
- why that GitHub object was correct;
- what permission boundary applied;
- what evidence proved success;
- what would have been over-engineering;
- whether the problem should trigger broader Research.
