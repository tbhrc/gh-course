# Certification

## GitHub Professional Operator — AI-First Founder Level

Certification will require demonstrated operating ability, not memorised definitions.

## Competency Areas

- Repository and Git fundamentals
- Issues and work management
- Branches and Pull Requests
- Projects
- Actions and automation
- Releases and versioning
- Knowledge architecture
- Security and governance
- AI-agent GitHub workflows
- GitHub × FolderDesk architecture judgement

## Final Assessment

The final assessment will require the learner to design and operate a complete change workflow from idea or bug through Issue, branch, implementation, Pull Request, checks, merge, release and audit evidence.
