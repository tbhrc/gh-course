One system, three surfaces

The website, Wiki and repository have different jobs. Together they form one governed learning environment.

🌐 GitHub Pages

Public website/front door. Gives students and external readers an easy place to start and routes them to the right live surface.

📖 GitHub Wiki

Reader handbook. Holds navigable course guidance, dashboards, manuals, epiphanies, SOP navigation and reference material.

🧱 GitHub Repository

Canonical operating record. Holds verified knowledge, curriculum, student evidence, Issues, branches, PRs, Actions, releases and history.

conversation / idea → GitHub Issue → branch / agent / execution → Pull Request → checks / review → merge → Actions → Wiki / Pages / release → durable evidence
