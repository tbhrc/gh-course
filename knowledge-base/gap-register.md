# GitHub Knowledge Gap Register

**Purpose:** track areas where the course, Skill or AI coach needs current verified knowledge before teaching or making an operating decision.

This is not David's personal learning gap list. Student-specific gaps live under `students/<student-id>/`.

## Status Key

- **Verified** — current authoritative source checked and durable note exists.
- **Mapped** — covered strategically by `github-power-user`, but not yet fully verified into the knowledge base.
- **Pending** — material gap still needs research/verification.
- **Hands-on pending** — platform knowledge exists, but course operation/evidence is still needed.

## Operating Rule

When a material gap is discovered:

```text
discover gap
→ record it here if reusable
→ verify primary source
→ create/update knowledge note
→ update relevant Skill/module only if useful
→ mark status accurately
```

Do not mark `Verified` merely because an AI model already knows the concept.
