# Question Bank

This directory is the reusable assessment bank for the GitHub Professional Operator course.

## Intended Contents

```text
question-bank/
├── README.md
├── diagnostic/
├── module-checkpoints/
├── scenario-tests/
└── answer-guides/
```

## Question Types

- definitions only where terminology matters;
- practical operator scenarios;
- explain-why questions;
- diagnose-a-problem questions;
- perform-this-operation exercises;
- architecture and judgement questions;
- final certification scenarios.

## Rules

- Prefer evidence of operating ability over trivia.
- Keep questions reusable across students.
- Store student answers under `students/<id>/assessments/`, not here.
- Answer guides should define the expected concepts and evidence, not force one exact wording.
- Version questions when their meaning materially changes so historical assessments remain interpretable.

## Assessment Model

A strong answer may be demonstrated through:

1. accurate explanation;
2. correct GitHub operation;
3. durable evidence such as an Issue, branch, Pull Request, workflow run or Release;
4. sound operator judgement about when a feature should or should not be used.

The final certification should test integrated operation, not memorisation.
