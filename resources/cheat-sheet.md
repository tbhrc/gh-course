# Operator Cheat Sheet

| Need | Default GitHub object/capability |
|---|---|
| Concrete task/bug/change | Issue |
| Isolated proposed change | Branch |
| Review + integration | Pull Request |
| Cross-work portfolio | Project |
| Deterministic event automation | Action |
| Hosted execution | GitHub-hosted runner |
| Local/private/special execution | Self-hosted runner when justified |
| Merge policy | Ruleset / branch protection |
| Ownership review | CODEOWNERS |
| Repository AI rules | AGENTS.md / instructions |
| Reusable multi-step method | Skill |
| Specialist recurring AI role | Custom agent |
| External tool/system access | MCP / API / connector |
| External OSS/tool discovery | Research |

## Default decision loop

```text
What problem?
→ Who owns the truth?
→ Which Skill/method applies?
→ Smallest native GitHub object?
→ Can normal capability execute safely?
→ Verify real state
→ Record durable evidence
→ Promote reusable learning only when justified
```
