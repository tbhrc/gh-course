# Student Profile — David

## Role in This Repository

David is Student #1 and the first public case study for this course.

He has explicitly agreed that his first name, starting knowledge, mistakes, answers, progress and learning journey may be documented publicly so the course can later be reused by other founders and learners.

## Learning Objective

Become a professional GitHub operator capable of using GitHub as a foundational operating platform for **Talent Bridge**, **iMPLEMENTAi** and **FolderDesk**, with particular strength in AI-agent workflows, traceability, history, automation, governance and operational design.

## Learning Style

- Learn by operating, not by passive theory.
- Use the repository itself as the training environment.
- Prefer concise explanations followed by hands-on execution.
- Focus deeply on demonstrated gaps rather than repeating known material.
- Connect concepts to real founder, company and AI-agent workflows.
- Preserve evidence of progress so later assessments can compare against the original baseline.

## Current Tool Context

David currently works with AI coding and general agents including Claude Code, Codex, ChatGPT and GitHub Copilot, commonly through VS Code or connected development environments.

He has not yet developed an operational GitHub-native AI-agent workflow using Issues, branches, Pull Requests, Actions and automated controls.

## End-State Statement

> GitHub should become a foundational operating platform for Talent Bridge, iMPLEMENTAi and FolderDesk where GitHub is genuinely the strongest native tool, while avoiding unnecessary duplication with other systems.

## Coaching Rule

Do not treat David as a generic beginner. He already understands several Git concepts and is an experienced AI-assisted operator, but his GitHub platform knowledge is currently limited. Teach the missing platform layer systematically and practically.
