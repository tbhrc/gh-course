# About This Learning System

The repository is simultaneously:

1. a practical GitHub course;
2. a live GitHub operating environment;
3. a reusable AI-coaching system;
4. a public learning case study.

## Learner Model

Each student gets durable state:

```text
students/<student-id>/
├── profile.md
├── baseline-YYYY-MM-DD.md
├── progress.md
└── assessments/
```

The baseline is historical evidence and must not be rewritten later to make the learner appear more knowledgeable.

## AI Coach Startup Model

```text
AGENTS.md
→ student profile
→ immutable baseline
→ current progress
→ Power User Skill
→ verified knowledge
→ current module
→ continue from demonstrated ability
```

## Evidence Model

The course deliberately records:

```text
original understanding
→ misconception/gap
→ correction
→ demonstrated understanding
→ partial recall
→ remaining mastery gap
```

Spontaneous epiphanies are also preserved when they materially change the learner's operating model.

## Why the Wiki Exists

The main repository is excellent for governance and source truth, but it is not always the fastest human reading experience.

The Wiki provides:

- a Home dashboard;
- handbook/manual navigation;
- course map;
- student progress summaries;
- epiphany history;
- reference/glossary;
- SOP navigation;
- links into canonical repository evidence.

## Governed Wiki Publishing

Wiki source lives under:

```text
wiki/
```

in the main repository.

Approved changes follow:

```text
Issue
→ branch
→ Pull Request
→ merge
→ GitHub Action
→ .wiki.git
→ live Wiki
```

The live Wiki is therefore a published view of governed source pages rather than an unmanaged parallel documentation system.

## Public Reuse

The learning system is designed so another founder, vibe coder or AI-assisted operator can reuse the course with their own student folder while keeping the shared curriculum and knowledge intact.
