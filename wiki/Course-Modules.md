## Current Learning Thread

The course temporarily moved into Module 07 because the Wiki itself became a valuable live learning environment.

```text

→ Actions
```

## Module Standard

Every substantial module should eventually contain:

1. concept;
2. operator value;
3. practical example;
4. hands-on GitHub task;
5. checkpoint/test;
6. evidence required for mastery;
7. official references.
